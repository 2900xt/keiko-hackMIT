# Machine-readable marine bioacoustics data sources — verified catalogue (checked 2026-09-19)

Legend: **V** = I fetched the page / listed the bucket / hit the API myself. **U** = unverified (from search snippets or secondary sources only). Sizes marked ">=" come from bucket scans that I capped at 12,000 objects.

## Headline findings
1. **Watkins (WHOI) is offline right now.** Both `cis.whoi.edu` and the `whoicf2.whoi.edu` mirror 302-redirect to `https://maintenance.whoi.edu` (curl + WebFetch, 2026-09-19). Everything below about its URL patterns comes from the Wayback Machine capture of 2024-08-10 (`web.archive.org/web/20240810115606id_/...`). The BEANS GCS zip (882 MB) and the Hugging Face parquet mirrors are the working fallbacks.
2. **The NCEI Google Cloud bucket `noaa-passive-bioacoustic` is the single richest anonymous endpoint**: it holds DCLDE 2011/2013/2015/2018/2022/2027, NEFSC, PIFSC, SanctSound, NRS, ADEON, JASCO, etc., all listable with no credentials via the JSON API.
3. **The Kaggle Watkins mirror (`shreyj1729/best-of-watkins-marine-mammal-sound-database`) returns 404** on both URL forms; treat it as gone. The Cornell/Right-Whale-Redux competition pages are JS-rendered (only `<meta>` text is fetchable), so their clip counts below are U.
4. **mobysound.org is dead** (parked Bluehost page). The DCLDE 2001–2013 archives it hosted are partially re-homed in the NCEI bucket (`dclde/2011/`, `dclde/2013/`).
