# Keiko detection database

Every whale detection the Keiko buoys report, kept in plain files in this folder so it can be cloned, diffed, cited, and opened in a spreadsheet without any tooling.

| file | what it is |
|---|---|
| `detections.csv` | one row per detection, the source of truth |
| `detections.json` | the same rows with typed values, read by the website |
| `buoys.csv` | buoy registry: id, name, position, hydrophone, sample rate |
| `clips/<id>.wav` | 16-bit mono PCM audio of the call |
| `spectrograms/<id>.png` | mel spectrogram of the clip, 0–1 kHz, RGBA: the site's blue ramp with quiet bins transparent |
| `schema.json` | JSON Schema for a detection row |

## Columns

`id`, `buoy_id`, `timestamp_utc`, `latitude`, `longitude`, `confidence` (0–1), `species`, `peak_hz`, `duration_s`, `sample_rate_hz`, `clip_path`, `spectrogram_path`, `source` (`field` or `synthetic`), `notes`.

Timestamps are ISO-8601 UTC. Paths are relative to this folder.

## Load it

```python
import pandas as pd
df = pd.read_csv("detections.csv", parse_dates=["timestamp_utc"])
df = df[df.source == "field"]          # drop the synthetic demo rows
```

```r
df <- read.csv("detections.csv")
```

Or straight from GitHub without cloning:

```python
base = "https://raw.githubusercontent.com/2900xt/keiko-hackMIT/main/site/data/"
df = pd.read_csv(base + "detections.csv")
```

## Add a detection

```sh
pip install -r ../tools/requirements.txt
python3 ../tools/keiko_data.py add --wav call.wav --buoy KEIKO-01 \
    --time 2026-09-20T14:03:11Z --lat 42.33 --lon -70.28 --confidence 0.87 --species humpback
```

That copies the clip, renders its spectrogram, appends the CSV row, and regenerates the JSON. Commit the result. If you edit the CSV by hand, run `python3 ../tools/keiko_data.py rebuild` afterwards.

## Status

Everything here so far is **synthetic** (`source = synthetic`), generated by `tools/keiko_data.py synth` to demonstrate the format. Field data will use `source = field`.
